# Contribuir

1. Crea una rama por cambio.
2. Mantén consistentes las reglas maestras de `docs/policy_matrix.csv`.
3. Ejecuta `pytest` y `python scripts/check_policy_consistency.py`.
4. No subas credenciales ni datos personales.
5. Describe el cambio y agrega pruebas cuando modifiques el flujo del agente.
